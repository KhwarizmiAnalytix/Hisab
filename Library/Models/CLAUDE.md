# Models

Stochastic-vol teachers and a QA-trained calibrator. See root `/CLAUDE.md`
for general coding/testing/build rules.

## What lives here

- `model/zabr.*` — SABR (Hagan 2002) and ZABR (γ ≠ 1 via ν_eff = ν α^{γ-1}).
- `calibration/zabr_calibrator.*` — Nelder–Mead fit of α, ν, ρ with β, γ
  fixed. `max_iter` caps the simplex. A provided `initial` with
  `max_iter <= 24` uses a tighter step (QA polish); longer runs keep the
  exploratory simplex.
- `calibration/qa_calibrator.*` — trained MLP inverse. Default
  `polish_iters=12` runs a short teacher polish; `0` is network-only.
- `nn/mlp.*` — ReLU MLP used at inference; weights in `nn/qa_zabr_weights.h`
  (generated by `Tools/models/train_qa_zabr.py`, not hand-edited). Inverse
  arrays keep the `k_*` names consumed by C++; `k_pricer_*` is the companion
  pricer trained in the same run.

Retrain after changing the teacher formula so C++ and the Python generator
stay in lockstep. Inverse input layout must stay
`(9 vols, T, log F, β, γ)`.

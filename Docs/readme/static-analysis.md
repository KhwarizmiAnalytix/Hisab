# Static Analysis

Static-analysis controls are module-scoped in CMake. The supported module
options are `<MODULE>_ENABLE_CLANGTIDY`, `<MODULE>_ENABLE_IWYU`, and
`<MODULE>_ENABLE_FIX`; there is no `PROJECT_ENABLE_CLANGTIDY`,
`PROJECT_ENABLE_IWYU`, or `PROJECT_ENABLE_CPPCHECK` cache variable.

## Recommended workflow

```bash
# clang-tidy for all loaded modules.
python Scripts/setup.py config.build.ninja.clang.debug.clangtidy

# Include-What-You-Use for all loaded modules.
python Scripts/setup.py config.build.ninja.clang.debug.iwyu

# Run the cppcheck helper after the build.
python Scripts/setup.py config.build.ninja.clang.debug.cppcheck

# Combine CMake integrations and the post-build cppcheck helper.
python Scripts/setup.py config.build.ninja.clang.debug.clangtidy.iwyu.cppcheck
```

The helper fans clang-tidy and IWYU flags to every loaded module. `cppcheck`
does not map to a library CMake cache variable; the helper invokes its own
post-build analysis step.

## Direct CMake

```bash
cmake -S . -B build-core-analysis -G Ninja \
  -DXSIGMA_LIBRARY_PROJECT=Core \
  -DCORE_ENABLE_CLANGTIDY=ON \
  -DCORE_ENABLE_IWYU=ON
cmake --build build-core-analysis --parallel
```

To apply a direct CMake analysis policy to the full project, set the matching
module-prefixed option for every library in scope. Separate build directories
are recommended because analysis tools can alter command lines and generated
compile databases.

## Tool requirements

- `clang-tidy` must be available on `PATH` for the clang-tidy integration.
- `include-what-you-use` must be available on `PATH` for IWYU.
- `cppcheck` must be available for the post-build helper.
- `compile_commands.json` is generated by `setup.py` for compatible analysis
  workflows.

## Fix mode

The `fix` helper token fans `<MODULE>_ENABLE_FIX=ON` and enables clang-tidy fix
options. Review the working tree before and after using it; automatic changes
may need manual follow-up.

## Bazel

The Bazel helper does not model clang-tidy, IWYU, cppcheck, or fix mode as
Starlark configurations. Use the CMake workflow for those tools.
